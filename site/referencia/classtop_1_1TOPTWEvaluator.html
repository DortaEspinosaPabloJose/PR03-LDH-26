Detailed Description

Evaluador de soluciones del TOPTW.

Clase reservada para centralizar el cálculo de la función objetivo de una TOPTWSolution. Actualmente el método evaluate() no está implementado (el cuerpo conserva comentado código heredado de un problema CVRP acumulativo). La puntuación de una solución se obtiene de momento mediante TOPTWSolution.evaluateFitness().
