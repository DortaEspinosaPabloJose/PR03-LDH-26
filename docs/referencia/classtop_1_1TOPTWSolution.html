Detailed Description

Solución del TOPTW: conjunto de rutas que visitan POIs respetando sus ventanas de tiempo.

Representación

Cada ruta es una lista circular doblemente enlazada que pasa por su depósito. Los enlaces se guardan en dos vectores indexados por identificador de nodo: predecessors y successors.

  • La ruta 0 usa el depósito 0; las siguientes usan copias del depósito con identificadores nodes + 1, nodes + 2, ... (ver addRoute()).
  • routes[k] contiene el identificador del depósito de la ruta k.
  • El sucesor del último cliente de la ruta es su depósito, y el predecesor del depósito es el último cliente.

Ejemplo de ruta con los clientes 5, 2 y 9 (depósito 0):

0 -> 5 -> 2 -> 9 -> 0
successors[0] = 5, successors[5] = 2, successors[2] = 9, successors[9] = 0

Una ruta vacía tiene al depósito como su propio predecesor y sucesor.

El identificador del nuevo depósito es el del último depósito creado más uno (el primero es nodes + 1). La ruta se registra en routes, se decrementa el número de vehículos disponibles, se enlaza el depósito consigo mismo y se informa al problema (TOPTW.addNodeDepot()).

◆ getInfoSolution()

String top.TOPTWSolution.getInfoSolution ( )

Genera un informe textual detallado de la solución.

Recorre cada ruta calculando los instantes de llegada y salida, y comprueba la factibilidad (ventanas de tiempo y duración máxima por ruta). El texto contiene:

  • un resumen: rutas en formato 0 - 5 - 2 - 0, si la solución es factible, la puntuación total y el coste de tiempo total;
  • los datos del problema y, por cada ruta, una tabla con coordenadas, ventana de tiempo, instantes de llegada y salida y tiempo de servicio de cada parada.
Returns
informe de la solución listo para imprimir.
