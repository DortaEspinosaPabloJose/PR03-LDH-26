Detailed Description

Par inmutable de dos valores de tipos posiblemente distintos.

Útil para devolver dos resultados desde un método o para usar pares como claves en colecciones, ya que implementa equals() y hashCode().

Ejemplo

Pair<String, Integer> p = Pair.create("POI", 7);
String name = p.first;
int id = p.second;

Calcula el código hash del par combinando con XOR los de sus elementos.

Note
