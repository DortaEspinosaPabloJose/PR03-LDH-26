Detailed Description

Iterable que recorre todos los subconjuntos (conjunto potencia) de un conjunto dado.

Para un conjunto de n elementos genera los 2^n subconjuntos, empezando por el vacío. Internamente usa un contador binario (BitSet) en el que cada bit indica si el elemento correspondiente forma parte del subconjunto actual.

Ejemplo

Set<Integer> base = new TreeSet<>(Arrays.asList(1, 2, 3));
for (Set<Integer> subset : new PowerSet<>(base)) {
System.out.println(subset); // [], [1], [2], [1, 2], [3], [1, 3], [2, 3], [1, 2, 3]
}

Note
Cada subconjunto devuelto es un TreeSet, por lo que los elementos deben ser comparables entre sí (Comparable); de lo contrario se lanzará ClassCastException. El número de subconjuntos crece exponencialmente con el tamaño del conjunto.
