Detailed Description

Lector de instancias del TOPTW desde fichero de texto.

Interpreta los ficheros del banco de pruebas (c1xx, r1xx, rc1xx) y construye un objeto TOPTW con todos sus datos y la matriz de distancias calculada.

Formato esperado

Los campos se separan por espacios o tabuladores (se normalizan con ExpositoUtilities.simplifyString()):

  1. Primera línea: cabecera. El campo 1 (índice 1) es el número de vehículos y el campo 2 el número de nodos (POIs).
  2. Segunda línea: se descarta.
  3. Líneas siguientes: nodes + 1 líneas, una por nodo (el nodo 0 es el depósito), con estas columnas (índice de campo):
Campo Contenido
1 Coordenada X
2 Coordenada Y
3 Tiempo de servicio
4 Puntuación
7, 8 Apertura y cierre de la ventana (sólo en el depósito)
8, 9 Apertura y cierre de la ventana (resto de nodos)

TOPTW top.TOPTWReader.readProblem ( String filePath)
static

Lee una instancia del problema desde un fichero.

Tras cargar los nodos calcula la matriz de distancias y fija el tiempo máximo por ruta igual al cierre de la ventana de tiempo del depósito.

Note
Ante un error de entrada/salida muestra el error por la salida de error estándar y finaliza el programa (System.exit(0)).
