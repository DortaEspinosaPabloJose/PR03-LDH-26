# RTVRPTW

**Recomendador Turístico con Ventanas de Tiempo.**

RTVRPTW construye itinerarios turísticos que **maximizan el interés total** de los puntos
visitados respetando sus horarios de apertura y el tiempo disponible. Internamente modela el
problema como un *Team Orienteering Problem with Time Windows* (TOPTW) y lo resuelve con la
metaheurística GRASP.
